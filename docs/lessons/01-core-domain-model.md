# Этап 01 — core-domain-model

## Цель

Описать маленькую C++20-модель проекта **только в памяти**, без JSON, файлов, CLI и Wasm.

## Первый учебный кусок

После принятия этапа 00 создайте только:

```text
packages/roadmap-core/src/roadmap/domain/roadmap-project.hpp
```

На первой итерации в нём понадобятся:

- `namespace roadmap`;
- один `enum class IntentStatus`;
- один `enum class StepStereotype`;
- `struct RouteStep` с `id`, `title` и векторами ID связей.

Полную модель сразу не пишите. Сначала пришлите этот маленький заголовок на ревью.

## Что нужно уметь объяснить после итерации

1. Почему `enum class` безопаснее произвольной строки для конечного набора состояний.
2. Чем владеет `std::string`.
3. Чем владеет `std::vector<std::string>`.
4. Почему связь с модулем пока хранится как ID, а не как адрес объекта.

Канонический объём всего этапа находится в § 20, этап 01 `roadmap-editor.plan.md`.
