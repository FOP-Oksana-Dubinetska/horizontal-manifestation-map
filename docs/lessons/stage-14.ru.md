# Stage 14 — сводная приёмка

## 1. Что получаем

Проверенный технический кандидат, матрицу всех обязательных сценариев и коллекцию диффов с точной базой. Авторская модель и её тесты сохраняются побайтно.

## 2. Файлы

Итоговый diff включает проверяющие инструменты, уточнения крайних случаев, полную неизменённую PLW-копию, реестры, карточки, матрицу и передачу. Состав каждого патча указан в series.json.

## 3. Проверка

```powershell
python tools/check-project.py --profile all
cmake --preset native-sanitize
cmake --build --preset native-sanitize
ctest --preset native-sanitize --output-on-failure
```

Санитайзеры проверяются в поддерживающей их среде; новый Windows gate и фактическая CF-публикация фиксируются отдельно по паспорту. Контрольный проход сохраняет отчёт и не устанавливает/обновляет зависимости, не форматирует исходники и не изменяет tracked-файлы.

## 4. Решение

Технические результаты и точные версии перечислены в отчёте передачи и TRACE. Автор самостоятельно воспроизводит §21.2 и определяет приёмку. Кандидат сохраняет отдельный статус от ратификации и публичного выпуска.
