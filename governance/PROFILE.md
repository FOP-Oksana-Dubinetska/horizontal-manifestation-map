# Учредительный профиль — кандидат

Редакция 2026-11-11. Подготовлен для рассмотрения владельцем; акт ратификации и вступления в силу отсутствует. Текущая реализация выполняет прямое поручение завершения и сохраняет технический кандидатный статус.

| Пункт | Положение |
| --- | --- |
| P01 | Horizontal Manifestation Map / HMAP; CLI, C++ engine и публичный встраиваемый web editor. Рабочий источник: pan-canon/TheWorldOfCanon/at-work/horizontal-manifestation-map; будущий owner: FOP-Oksana-Dubinetska. |
| P02 | Обязательные upstream-условия и LICENSE.md имеют приоритет в своих областях; пользовательские карты сохраняют собственные права. |
| P03 | Автор проекта определяет продуктовый замысел через ТЗ и явные поручения; ассистент подготавливает кандидата. |
| P04 | План определяет требования; JSON — данные карты; код, Markdown и сборки имеют объявленные самостоятельные роли. |
| P05 | Владелец принимает продукт и нормы. Ассистент реализует и сообщает технические результаты; это не акт человеческой приёмки. |
| P06 | Изменение плана, схемы либо правил сопровождается diff, источником решения, тестом и TRACE. |
| P07 | Выпуск и переключение production выполняет владелец целевого репозитория/Cloudflare аккаунта. |
| P08 | Спор о сохранении смысла фиксируется в normative translation; решение остаётся за владельцем. |
| P09 | Domain/application отделены от форматов, CLI files, Worker, DOM и storage. |
| P10 | Начальная ратификация ожидает отдельной записи владельца. Техническая подготовка 2026-11-11 сохраняется в TRACE. |
| P11 | Поправки профиля принимает владелец с указанием ревизии и перехода. |
| P12 | JSON-канон, границы ядра/среды и человеческая приёмка сохраняются защищаемыми основаниями предлагаемого профиля. |
| P13 | Подтверждённые платформы и пределы перечислены в матрице; новый Windows gate и публичный CF smoke выполняются владельцем. |
| P14 | При ошибке кандидата сохраняется последняя корректная карта; rollback возвращает согласованный комплект JS/Wasm. |
| P15 | TRACE, точные SHA, lockfiles, измерения и отчёты составляют свидетельства конкретной редакции. |
| P16 | Блокирующие технические проверки задаются реестром; изменяет их владелец с причиной и новой проверкой. |
| P17 | Схемы мигрируются явно; исходный файл сохраняется; релизная отмена описывается отдельно. |
| P18 | Практики Stage 00–02 считаются историческими свидетельствами и не получают нормативной силы автоматически. |
