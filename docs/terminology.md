> Since Stage 16 the ordinary workspace uses fixed engineering labels. The four profiles remain a compatible JSON/CLI/API capability; a host must explicitly enable terminologySelector to show their selector.

# Terminology

Engineering/simple/product/literary change display labels through the shared guidance catalog. Interface language en/ru is independent. Machine keys, IDs, enum values and graph semantics remain stable. `docs/guidance/catalog.json` is the canonical bilingual source; the engine embeds it for both CLI and Web. Ukrainian localization remains a separate next task.
