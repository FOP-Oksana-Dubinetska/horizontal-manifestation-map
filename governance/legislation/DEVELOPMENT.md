# Development profile — candidate

The author request authorizes a completed technical candidate inside the specified project. The owner reviews content, adopts norms and releases. This profile remains draft for that adoption. Existing Stage 00–02 observations are retained as history. Later stages use the same goal → files → implementation → deterministic check → TRACE sequence, with completed candidate patches prepared under the explicit request.

C++ uses C++20, kebab-case files, PascalCase types, camelCase functions/values and explicit value ownership. New code follows `.clang-format`; the original model and its learning tests retain their authored bytes. GCC/Clang warnings are Wall/Wextra/Wpedantic and own-code warning failures block the consolidated native gate. ASan/UBSan use a separate native preset. TypeScript is vanilla, with the pinned formatter for own UI/storage sources. The control pass never reformats or installs dependencies.

Domain/application code uses its own structures and standard library. Format adapters contain nlohmann/json. CLI files/terminal behavior stay in the CLI composition root; Embind stays in the Wasm entry. Browser storage is injected by the host and verified through the common C++ codec. Public UI state and canonical project state have separate lifecycles.

Schema changes require a declared version and explicit migration. User strings, existing IDs, timestamps and rejected-source bytes are preserved. Technical regulators list their source, owner and modification procedure. Any change to a regulator updates its fixture and evidence. Protected product constraints are JSON source, one-route layout, local processing and human acceptance.

Pinned PLW and Constitution/policy references remain unchanged. The method validator proves structural candidate readiness. It grants no acceptance authority and does not substitute for review of normative meaning. Required release evidence covers native/Wasm parity, storage faults, browser lifecycle, static resources, licenses, complete AC mapping and owner observations of Windows/public hosting.
