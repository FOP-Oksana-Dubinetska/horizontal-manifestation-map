# Stage 02.3b

## 1. Что получаем

Автоматически проверить реальный контракт потоков и кодов CLI. Исходное ТЗ и его данные остаются опорой следующего шага.

## 2. Файлы этого диффа

- `CMakeLists.txt`
- `CMakePresets.json`
- `TRACE.md`
- `manifest/prepared-dependencies.json`
- `tests/cli-shell.test.cpp`
- `tools/prepare-dependencies.py`

## 3. Как проходит управление

`main` передаёт аргументы и потоки в `runCli`; парсер создаёт типизированные параметры; ошибки и успешный результат идут по разным потокам. Тест владеет ostringstream и проверяет код процесса без второго main.

## 4. Проверка

Команды выполняются из корня проекта; Emscripten предварительно активируется для Wasm. CLI-привязка операций JSON/Text/inspect объединяется в Stage 08; до него проверяются самостоятельные библиотеки через CTest.

```powershell
cmake --preset native-debug
cmake --build --preset native-debug
ctest --preset native-debug --output-on-failure
```

## 5. Фиксация результата

В TRACE уже включены фактически наблюдавшиеся проверки подготовленного кандидата. После собственного запуска добавьте локальный результат и имя среды. PASS означает проверенный технический контракт; содержательное принятие остаётся решением автора.
