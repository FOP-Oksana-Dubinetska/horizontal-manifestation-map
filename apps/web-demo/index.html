Архитектура и маршрут

					

						Намерение задаёт результат и критерии. Компоненты описывают архитектуру. Контракты
						объясняют решения. Маршрут связывает шаги реализации с этими компонентами и контрактами.
					

					
    
						
  1. Создайте карту или измените пример кнопками «Изменить».
    2. 
						
  2. Через «+ Добавить» создайте намерение, компоненты, контракты и маршрут.
    3. 
						
  3. Добавьте шаги. В их формах выберите связанные компоненты и контракты.
    4. 
						
  4. 
							Нажмите шаг, чтобы выделить связанные элементы выше. Для изменения шага используйте
							отдельную кнопку «Изменить».
						
    5. 
						
  5. 
							Примените форму и сохраните карту. Файл → Скачать JSON позволяет перенести её в другой
							браузер через «Импорт».
						
    6. 
					

					

						Один компонент может использоваться в нескольких маршрутах. Ссылки сохраняются при
						изменении названия. Сохранённые карты открываются через меню «Файл».
					

					

						Сведения о формате
						

							Schema 2. Общий C++/WASM-движок проверяет карту перед принятием изменений.
							Терминологические профили сохранены для совместимости файлов. Сохранение выполняется в
							этом браузере; Markdown служит читаемым экспортом.
