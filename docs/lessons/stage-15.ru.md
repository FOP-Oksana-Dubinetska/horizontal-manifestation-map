# Stage 15 — кандидаты авторских изменений

## 1. Что получаем

Ограниченную программу следующего выпуска и чистые операции над копией schema-2 карты: создание, выдачу свободного ID, перестановку и подготовку удаления с перечнем последствий.

## 2. Файлы этого диффа

`hmap-authoring.plan.md`, `CONTRACTS.md`, `SCENARIOS.md`, `packages/roadmap-ui/src/authoring.ts`, `tests/web/authoring.test.ts`, `package.json`, эта карточка и `TRACE.md`.

## 3. Контракт

Вход — последняя принятая карта и выбранный объект. Выход — самостоятельный кандидат. Исходный объект сохраняется. Удаление намерения включает его маршруты и шаги; общие компоненты и текст сохраняются, ссылки снимаются явно. Пересечения с менее чем двумя источниками входят в объявленный перечень удаления. Операции готовят данные; принятие требует C++ validator на следующем этапе.

## 4. Проверка

```powershell
npm run test:storage
npm run typecheck
```

Наблюдаемый результат: 9/9 тестов (6 авторских операций + 3 хранения), TypeScript PASS. Первый запуск выявил неподдерживаемый parameter property в Node strip-only; поле объявлено явно, зависимости сохранены. Имена тестовых файлов перечислены явно для Windows shell.

## 5. Фиксация и следующий шаг

Проверки пройдены; следующий шаг связывает эти операции с интерфейсом. Далее Stage 16 — доступные формы и применение через общий движок.
